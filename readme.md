# Programación IV

## Objetivo principal

Desarrollar competencias en **programación y desarrollo de aplicaciones móviles**, aplicando diferentes tecnologías, frameworks y herramientas de desarrollo para la creación de aplicaciones funcionales, escalables y orientadas a resolver necesidades reales.

## Tecnologías utilizadas

### Node.js
Entorno de ejecución basado en JavaScript que permite desarrollar aplicaciones y servicios del lado del servidor de manera eficiente y escalable.

### React Native
Framework basado en React que permite desarrollar **aplicaciones móviles multiplataforma** para Android e iOS utilizando JavaScript y componentes nativos.

### Kotlin
Lenguaje de programación moderno desarrollado por JetBrains, ampliamente utilizado para el **desarrollo de aplicaciones Android**, caracterizado por su sintaxis concisa, seguridad y compatibilidad con Java.

### Flutter
Framework desarrollado por Google que permite crear **aplicaciones multiplataforma** desde una única base de código, utilizando el lenguaje Dart.

### Dart
Lenguaje de programación desarrollado por Google y utilizado principalmente con Flutter para construir aplicaciones multiplataforma con un alto rendimiento y una estructura orientada a objetos.

## Contenido

Este repositorio contiene los proyectos, prácticas y ejercicios desarrollados durante la asignatura **Programación IV**, aplicando diferentes tecnologías y herramientas relacionadas con el desarrollo móvil y de aplicaciones.
